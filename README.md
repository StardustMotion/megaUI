# MegaUI
*An ACS library / tool for designing and implementing UIs in Zandronum*

## Development

- `git clone https://github.com/StardustMotion/megaUI.git megaUI`
- Source control / build / run the pk3 with [Can't Believe It's Not Slade](https://gitlab.com/Trillster/cbins) :
    - `cd megaUI`
    - `./run.sh` (edit `run.sh` with your Zandronum path)
    - Edit code with `Visual Studio Code` or another text editor
- Adheres to [semantic versioning](https://semver.org/) and [keep a changelog](https://keepachangelog.com/en/1.0.0/)
